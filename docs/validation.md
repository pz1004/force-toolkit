# Validation

Run commands from an extracted source archive with the 0.2.1 wheel installed. Run library tests with the test dependencies installed. The [release evidence bundle](https://github.com/pz1004/force-toolkit/releases/download/v0.2.1/force-toolkit-evidence-0.2.1.zip) contains the 0.2.1 MAD outputs, checksums and Linux verification results.
